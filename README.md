# Nhim Dara Portfolio

A personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and GSAP.

## Project structure

```text
src/
├── assets/images/       # Static image assets
├── components/
│   ├── layout/          # Site-wide layout components
│   └── ui/              # Reusable interface and animation components
├── hooks/               # Reusable React hooks
├── sections/            # Portfolio page sections grouped by feature
├── App.jsx              # Page composition
├── index.css            # Global styles
└── main.jsx             # Application entry point
```

## Development

```bash
npm install
npm run dev
```

Use `npm run lint` to check the source and `npm run build` to create a production build.
